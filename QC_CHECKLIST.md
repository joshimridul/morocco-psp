# Human Review Checklist

## Storage and provenance

- [ ] The GitHub repository contains no student data, item maps, instruments, keys, secure item text, or data-bearing outputs.
- [ ] `config/paths.local.yml` is untracked and contains the only machine-specific Dropbox paths.
- [ ] All three legacy Dropbox roots were treated as read-only.
- [ ] No generated file was written beneath a legacy root.
- [ ] Every source input is registered with a root alias, relative path, hash, and selection status.
- [ ] No source was declared canonical solely because of a `Clean` folder, latest date, or replication-package location.
- [ ] No conflicted, recovered, draft, old, or archive copy was silently selected.
- [ ] Legacy `.do` and `.R` files were not opened or executed before the authorized legacy-code phase.
- [ ] Any later execution of inherited code occurred in an isolated workspace with outputs redirected away from the legacy roots.

## Data and measurement

- [ ] All student data are deidentified and authorized for this environment.
- [ ] Every year/wave/cohort/sample/form/grade has a unique identifier.
- [ ] Administered grade, paper level, item grade of origin, and target grade are distinct fields.
- [ ] Item versions are verified against actual materials, not inferred from IDs.
- [ ] Computed scores tie to operational scores or discrepancies are explained.
- [ ] Missing, not-reached, invalid, and omitted responses are distinguished.
- [ ] Passage/testlet and rubric structures are represented.
- [ ] Pilot, main, cohort, panel, treatment, and control samples were not silently pooled.
- [ ] Item screening did not use treatment-effect size or significance.
- [ ] Candidate anchors are defined separately by linking purpose.
- [ ] Anchor sets cover content and difficulty, not just statistical cleanliness.
- [ ] DIF/drift decisions use effect sizes and uncertainty, not p-values alone.
- [ ] Development and validation are separated by school/cohort/wave/sample.
- [ ] Domain scores have enough independent tasks and acceptable precision.
- [ ] Form simulations respect curriculum, timing, exposure, and rater constraints.
- [ ] Raw-score and model-based conclusions are compared.
- [ ] The Y1–Y3 form-and-sample graph was built before any common scale was claimed.
- [ ] Year 1 was not forced onto the Y2–Y3 scale without substantive and empirical linking evidence.
- [ ] Every final number is generated by reproducible tracked code.
- [ ] Independent QC has been completed before communicating recommendations.
