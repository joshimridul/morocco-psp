# No project data belong in this repository

All Year 1, Year 2, and Year 3 data, item maps, instruments, answer keys, rubrics, and data-bearing outputs remain in Dropbox.

Connect the repository to the local Dropbox folders through the untracked file `config/paths.local.yml`, using `config/paths.example.yml` as a template. Do not copy, symlink, or commit Dropbox data here.
